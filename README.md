# 🍰 MySweetheart Landing Page

Landing page responsif dan interaktif untuk toko kue dan dessert "MySweetheart". Website ini dirancang untuk menampilkan katalog produk secara menarik sekaligus memudahkan pelanggan melakukan pemesanan langsung melalui WhatsApp.

## ✨ Fitur Utama

- **Katalog Menu Dinamis:** Menampilkan foto produk asli, deskripsi, dan harga.
- **Keranjang Belanja Pintar:** Pengunjung dapat menambah, mengurangi, atau menghapus pesanan dengan mudah lewat laci keranjang (_sidebar_).
- **Checkout Langsung ke WhatsApp:** Formulir pemesanan terintegrasi yang otomatis merekap pesanan, total harga, dan data pelanggan menjadi pesan teks WhatsApp yang rapi.
- **Desain Responsif:** Tampilan yang menyesuaikan dengan sempurna di layar laptop, tablet, maupun smartphone.

## 🛠️ Teknologi yang Digunakan

- **HTML5** untuk struktur halaman.
- **Tailwind CSS (via CDN)** untuk _styling_ dan desain responsif.
- **Vanilla JavaScript** untuk logika interaksi keranjang belanja dan _checkout_.

## 🚀 Cara Menjalankan Secara Lokal

1. _Clone repository_ ini: `git clone https://github.com/Raihansatr/mysweetheart.git`
2. Buka folder proyek.
3. Klik dua kali pada file `index.html` untuk membukanya di browser pilihan Anda.
